# 🏧 Sistema ATM - TecBank201D

Simulador de cajero automático desarrollado en **C++**, diseñado como un prototipo funcional que implementa programación modular, control de transacciones financieras y validaciones de seguridad.

---

## 🚀 Características Principales

* **Autenticación Segura:** Validación de PIN de acceso con bloqueo de cuenta tras intentos fallidos.
* **Consulta de Saldo:** Visualización en tiempo real del saldo disponible en cuentas.
* **Depósitos y Retiros:** Operaciones con validación de fondos y entrega estructurada de billetes.
* **Transferencias:** Envío de fondos entre cuentas con confirmación previa.
* **Historial de Movimientos:** Registro dinámico de las últimas transacciones realizadas.

---

## 🛠️ Tecnologías y Entorno

* **Lenguaje:** C++
* **Entorno de Desarrollo:** Visual Studio Code con compilador `g++` (MinGW-W64)
* **Control de Versiones:** Git y GitHub

---

## 📂 Estructura del Proyecto

* `main.cpp` - Lógica principal de operaciones bancarias y consola.
* `main_gui.cpp` - Interfaz visual adaptada para consola con mejoras de diseño.
* `build.ps1` - Script de automatización para compilación.
